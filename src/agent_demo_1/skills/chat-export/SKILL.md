# 聊天记录导出

- 用户要求执行导出时，选择 `chat-export` 技能和 `direct` 路径。
- 例如：“导出聊天记录”“把这段对话保存成 md”“下载当前聊天”。
- 用户只是询问如何实现或使用导出功能时，不执行此技能。
- 调用 `export_chat_history`，使用本次请求提供的 `history`。
- 按原顺序保留用户和助手的消息正文，不总结、不改写。
- 不包含本次导出指令、导出回复、系统提示词、工具消息或内部执行过程。
- 将 UTF-8 Markdown 文件保存到 `static/output`，使用唯一文件名。
- 文件生成后返回下载信息；历史记录为空时说明没有可导出的记录。
